- Title: How We Make Yoga Classes Easier to Find Online
- Meta description: How Yog Jivan organises English and Vietnamese pages, clear class options and on-site search so students find the right class — practical steps for studios and agency partners.
- Audience: studio owners and agency partners.
- Angle: first-hand, verifiable walkthrough of this site's structure. No ranking or traffic claims.

## Outline
1. Start from what students actually ask
2. One page per real class option
3. English and Vietnamese: separate, indexable pages
4. Clear choices on the page (group vs private)
5. Internal search that understands everyday words
6. Internal links that follow the reader's next question
7. What to avoid
8. Checklist

## 1. Start from what students ask
List the questions you hear on WhatsApp, Zalo and at the desk ("Do you have private online classes?", "Is there a class near me in Hải Dương?"). Each recurring question should map to one clear page or section.

## 2. One page per real option
Yog Jivan keeps distinct pages for distinct choices, e.g. private 1-on-1 online (https://www.yogjivan.com/private-online-yoga) and live online group classes (https://www.yogjivan.com/online-yoga-classes). Avoid several near-identical pages for the same intent.

## 3. English and Vietnamese
A language toggle alone does not create Vietnamese pages search engines can index. Each Vietnamese page has its own URL, e.g. https://www.yogjivan.com/vi/lop-yoga-online and https://www.yogjivan.com/vi/yoga-1-kem-1-online, with language alternates pointing between EN and VI versions.
*Proof needed:* screenshot of the page source showing hreflang alternates.

## 4. Clear class options
Near the top of the online page, visitors choose between live group classes and private 1-on-1. Prices shown are the same ones the studio confirms — never estimates.

## 5. Internal search
The site search is built automatically from each public page's title and description, so new pages appear without a hand-maintained list. It understands accents and everyday variants (e.g. "yoga cặp đôi" / "couples", "1 kèm 1" / "private").
*Proof needed:* screen recording of searching "yoga 1 kèm 1" and "couples yoga" on desktop and mobile.

## 6. Internal links
Each page links to the reader's next step (e.g. from a beginner guide to the class that suits beginners), using descriptive link text rather than "click here".

## 6b. Meaningful menu names
Menu labels use the words students use ("Private Online Yoga", "Couples Yoga", "Family Yoga", "Corporate Yoga", "School / Kids Yoga"; VI: "Yoga 1 kèm 1", "Yoga cặp đôi"…), grouped so the main choices are visible without opening many levels.
*Proof needed:* screenshot of the open desktop and mobile menu.

## 6c. A first-time walk-through
Ask someone who has never seen the site to find (1) a private online class, (2) the studio nearest to them, (3) how to contact the team — in English and in Vietnamese. Note where they hesitate and fix that label or link first.

## 7. What to avoid
Keyword-stuffed pages, copied location pages, invented reviews or statistics, and automatic translations published without review.
